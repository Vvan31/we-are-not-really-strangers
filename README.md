# Closer, Together

A small, self-contained conversation game for couples. Choose a topic, take turns with original prompts, reveal an optional follow-up, and save questions to revisit later.

## Run it

Open `index.html` directly in a browser. The app has no build step or package dependencies. The interface uses a Google Fonts stylesheet when online and falls back to system fonts offline.

## Features

- Four conversation modes: a mixed set, everyday life, shared stories, and future hopes
- A shuffled prompt deck with optional deeper follow-ups
- Saved prompts stored in this browser using local storage
- Responsive layout, keyboard focus styling, and reduced-motion support
- A gentle reminder that either person can pass or pause
